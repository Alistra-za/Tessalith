# Mistakes log

Three files: `general.md` (machine, shell, git and build), `engine.md` (crates/engine, crates/cli, crates/encoders-sys) and `gui.md` (crates/gui). The NIF team's crates get `nif.md` with their first entry.

- **Before you start:** read `general.md` and the file for your area.
- **When something goes wrong** that the next agent would hit too, append one line to that file.
- **Entry format:** `- YYYY-MM-DD <what went wrong> → <what to do instead> (<where: file or command>)`.
- A rule the owner decided goes in `.claude/DECISIONS.md`, not here.
